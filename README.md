# Edito — Site Profissional

Site desenvolvido para apresentar meu trabalho como editor de vídeos e fortalecer minha presença profissional na internet.

## Sobre o projeto

O Edito surgiu da necessidade de criar uma presença digital própria para divulgar meus serviços de edição de vídeos, apresentar meu portfólio e facilitar o contato com possíveis clientes.

Embora a edição de vídeos não esteja diretamente relacionada à minha formação em Engenharia de Software, as duas áreas acabaram se complementando. A experiência profissional com edição despertou a necessidade de desenvolver uma solução digital própria, permitindo aplicar na prática conhecimentos de desenvolvimento web.

Este projeto representa a conexão entre minha experiência profissional e meu aprendizado na área de tecnologia.

## Objetivos

- Apresentar meus trabalhos de edição de vídeos.
- Divulgar meus serviços para empresas e criadores de conteúdo.
- Facilitar o contato com potenciais clientes.
- Aplicar conhecimentos de desenvolvimento web em um projeto real.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
